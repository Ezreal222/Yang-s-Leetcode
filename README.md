# Yang-s-Leetcode

Bilingual (English + 中文) LeetCode notes & solutions in Python, C++, Java.

📖 **Site**: https://Ezreal222.github.io/Yang-s-Leetcode/

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000.

## Structure

- `docs/` — all notes, organized by category (`NN-category/NNNN-slug/README.md`).
- `docs/_template/problem-template.md` — template every new problem starts from.
- `mkdocs.yml` — site config (mkdocs-material).
- `.github/workflows/deploy.yml` — auto-deploys to GitHub Pages on push to `main`.
