# 13 · Binary Search / 二分查找

**EN**: Classic binary search (on sorted arrays), binary search on answer (BSA), and binary search variants. The unifying signal: a **monotone predicate** over a search range.

**中文**: 经典二分 (有序数组上找值), 二分答案 (BSA), 以及变种. 共同信号: 某个**单调判定**在搜索空间上.

> **何时反应二分**: ① 有序数组找值/前驱后继; ② "最小化最大值 / 最大化最小值" → BSA + 贪心 check; ③ 关于答案的条件是单调布尔函数.
